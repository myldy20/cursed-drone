# Установка Cursed Drone 1.0.0 на Android

Cursed Drone 1.0.0 — функционально завершённый релиз. Android-сборка — сенсорный **ARM64-пакет для ручной установки** на Android 8.0 и новее. Звуковое ядро, места, эффекты и формат сессии совпадают с версиями для приставки, macOS и WebAssembly. Android и Web используют один адаптивный полноэкранный интерфейс для горизонтального экрана.

1. Скачай `cursed-drone-v1.0.0-android-arm64-preview.apk` из GitHub Release.
2. Разреши установку из браузера или файлового менеджера, которым открыт APK.
3. Установи и запусти приложение; при необходимости поверни телефон горизонтально.

APK собран с release-оптимизацией, но по-прежнему подписан для публичной ручной установки, а не для production-публикации в Google Play. Версия проекта 1.0 означает зрелость функций и совместимости, но не превращает APK в Play Store-пакет. Сборка с другой подписью в будущем может потребовать сначала удалить прежнее приложение.

Autosave, восемь слотов и пользовательские Scala-файлы хранятся в приватных данных приложения. При удалении приложения они тоже удаляются, если Android не восстановит резервную копию. Перед переустановкой отдельно сохрани важные настройки патчей.

Сенсорный workflow: прямые вкладки страниц, mute на карточках актёров, перетаскиваемые слайдеры и модальные сетки. На вкладке событий актёра доступны Trigger Now, Event Rate/FMAX и Euclidean; Scala-строй и макромодели Musical находятся на вкладке звука актёра.

Для отчётов о надёжности смотри [поддержку и расположение логов](support.ru.md).
