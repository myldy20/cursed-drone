# Cursed Drone 0.13.1

Version 0.13.1 is the public multi-platform release of the unified Cursed Drone core and the hardware-validated Android frontend. It uses a patch version because the earlier `v0.13.0` tag already existed before the final Android and repository-release work was completed.

## Highlights

- new fullscreen touch-first Android ARM64 frontend;
- the same scenes, actors, Musical engine, Scala tuning, modulation, Actor FX, Master FX and session format on every platform;
- Android launcher icon based on the original Cursed Drone mark;
- direct touch routing, persistent `KILL`, reliable final slider values and eight local memory slots;
- independent effect enable/bypass state without losing the selected effect or its parameters;
- control-rate DSP optimisations, cached pan curves and complete suspension of muted actors;
- improved DC blocking and realtime instrumentation;
- unified versioning, CMake graph and CI for macOS, Android, PortMaster and NextUI;
- preserved schema-11 session compatibility through migration to schema 12.

## Android status

The Android build is a public sideload preview for Android 8.0 or newer and ARM64 devices. It is release-optimised but signed with the project preview key rather than a Google Play production key. App data is stored in Android private storage and is removed when the app is uninstalled unless the operating system restores a backup.

The interface has been validated on a Pixel 8 Pro. The Android release retains the landscape-only layout and the current five-page workflow: Place, Actor, FX, Master and Memory.

## Performance note

On the reproducible desktop benchmark used during development, the default Derelict scene rendered about 20% faster and the 20× Black Hole stress case about 70% faster than 0.12.3. These are comparative development measurements; actual load on TrimUI Brick depends on firmware, clock and the selected scene.

## Known limitation

The stored `morph` fields remain intentionally hidden because landscape morphing is not yet implemented in the shared DSP path. No non-functional control is exposed in the UI.
