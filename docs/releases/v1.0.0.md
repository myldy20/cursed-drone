# Cursed Drone 1.0.0

Cursed Drone 1.0.0 is the feature-complete release of the standalone instrument.

The original roadmap is complete: one shared C++ audio core now ships as a controller-first TrimUI/desktop application, a touch-first Android application and a public WebAssembly build. The project moves to maintenance mode after this release. New instrument concepts and larger performance-system ideas will be developed as modules for BRKSTN rather than added to Cursed Drone.

## Field-tested performance baseline

The maintainer tested the release candidate across the supported personal hardware:

- **TrimUI Brick:** approximately 50% DSP load in ordinary use; the highest observed load stayed below 80%, including deliberately heavy scenes and effects;
- **Pixel 8 Pro:** low observed load with no noticeable audio, lifecycle or interface failures during testing;
- **macOS browser:** low observed load with no noticeable audio or interaction failures during testing.

These are practical field observations, not laboratory guarantees. Firmware, browser versions, clock settings, audio routing and unusually dense patches can change the result. Musicians planning live use should rehearse the exact set, keep the tested build unchanged before the show and retain a fallback audio source.

## Final hardening work

- retain the 0.14.1 session sanitisation, atomic saves and `.bak` recovery;
- retain prompt Android lifecycle saves and serialised Web IndexedDB flushing;
- retain control-rate Scala quantisation and the existing realtime DSP optimisations;
- retain automated Web mouse, touch, DPR 1/2, Retina and drag-interaction tests;
- publish the field-tested performance envelope and known platform limitations;
- expand the Musical model, macro-control and MAIN/AUX/MIX/STEREO documentation;
- add a structured GitHub bug-report form requiring platform, version, reproduction steps and logs;
- replace the feature roadmap with an explicit maintenance policy.

## Product status

Cursed Drone 1.0.0 is considered complete for its intended purpose: a small, strange, immediately playable procedural soundscape instrument.

Future repository changes are limited to:

- reproducible crashes, data loss or severe audio failures;
- compatibility fixes for supported platforms;
- security, licensing and build-system maintenance;
- documentation corrections.

Feature requests are not part of the maintenance plan.

## Supported release targets

- TrimUI Brick with Knulli/PortMaster;
- TrimUI Brick with NextUI;
- macOS Apple Silicon;
- Android ARM64, Android 8.0 or newer;
- modern desktop and mobile browsers with WebAssembly and Web Audio.

The Android APK remains a manually installed, release-optimised sideload package rather than a Google Play production package. That distribution limitation does not change the feature-complete status of the instrument.

## Reliability statement

No release-blocking defect is known at publication time, and all supported builds are produced from the same core and validated by CI. This is still independent experimental music software, not certified stage infrastructure. Reliability reports should use the repository bug form and include the exact build, device, firmware or browser, reproduction steps and available logs.
