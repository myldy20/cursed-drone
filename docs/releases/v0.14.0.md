# Cursed Drone 0.14.0

Version 0.14.0 is the first public browser release of Cursed Drone and the first release where the approved Android interface is shared directly with WebAssembly. The audio core, session format, synthesis catalogue, effects and version source remain common across every supported platform.

## Highlights

- public WebAssembly/Web Audio build hosted on GitHub Pages;
- shared adaptive Place, Actor, FX, Master and Memory interface for Android and Web;
- desktop mouse, drag and touch input through one SDL interaction path;
- correct click alignment on Retina/HiDPI and letterboxed desktop windows;
- fullscreen entry and re-entry controls, Russian/English launch screen and mobile landscape guidance;
- IndexedDB autosave and eight persistent browser memory slots;
- browser-specific audio buffering and idle rendering cadence without changing native Android latency settings;
- complete Musical model selection, MAIN/AUX/MIX/STEREO routing, Scala root/scale controls and aligned slider tracks;
- automatic WebAssembly previews on pull requests and GitHub Pages deployment from `main`.

## Supported downloads and launch targets

- **Web:** launch from the GitHub Pages link in the repository README;
- **PortMaster / Knulli:** `cursed-drone-v0.14.0-portmaster-aarch64.zip`;
- **NextUI / TrimUI Brick:** `cursed-drone-v0.14.0-nextui-tg5040.zip`;
- **Android ARM64 public preview:** `cursed-drone-v0.14.0-android-arm64-preview.apk`;
- **macOS Apple Silicon:** `cursed-drone-v0.14.0-macos-arm64.zip`.

The web build is delivered continuously from the same `main` commit. Downloadable release assets include `SHA256SUMS.txt`.

## Browser input fix

SDL already remaps finger events into the renderer's fixed 1496×672 logical viewport when `SDL_RenderSetLogicalSize` is active. The browser frontend previously converted those coordinates a second time, moving compact button hit areas below the rendered controls on letterboxed desktop displays. Version 0.14.0 removes that second conversion. The final preview was verified with centre clicks on the Actor tab and KILL control at 1440×900 with device-pixel ratio 2.

## Performance baseline

The realtime optimisations introduced in 0.13.1 remain in place: bounded control-rate updates, cached equal-power pan curves, suspension of muted actors, constant-time Kill and atomic persistence. The web target adds its own buffering and render-cadence policy so browser scheduling does not alter the native platform paths.

## Known limitations

- real landscape morphing is not implemented; stored morph fields remain hidden;
- browser audio latency and stability depend on the operating system, browser and device power policy;
- importing custom Scala files is platform-dependent, while bundled scales are available everywhere;
- the Android APK remains a release-optimised sideload preview rather than a Play Store build.
