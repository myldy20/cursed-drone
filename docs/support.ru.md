# Поддержка и отчёты о надёжности

Cursed Drone считается функционально завершённым. Проект поддерживается ради воспроизводимых ошибок, потери данных, серьёзных сбоев звука и совместимости с заявленными платформами. Новые функции в план поддержки не входят.

## Перед созданием тикета

1. Проверь проблему на последнем опубликованном релизе.
2. Перезапусти приложение и повтори ту же последовательность действий.
3. Запиши точную версию, устройство, операционную систему или прошивку и браузер, если он используется.
4. Опиши минимальную последовательность, которая стабильно вызывает проблему.
5. Приложи доступный лог, не вырезая строки непосредственно перед сбоем.

Используй форму **Bug report / reliability issue** в GitHub Issues. Без версии, платформы и сценария воспроизведения отчёт может оказаться непригодным для диагностики.

## Где брать логи

### Knulli / PortMaster

Приложение обычно находится в `roms/ports/curseddrone/`. Полезные файлы лежат в `curseddrone/conf/`:

- `cursed-drone.log` — вывод последнего запуска;
- `device-probe.log` — аппаратная и SDL-диагностика первого запуска;
- `autosave.cdrone` и `.bak` — прикладывай только при проблемах загрузки или восстановления и только если в сессии нет ничего приватного.

### NextUI

Лог по умолчанию:

`/.userdata/tg5040/logs/Cursed Drone.txt`

Данные приложения обычно находятся в:

`/.userdata/tg5040/cursed-drone/`

### Android

Укажи модель телефона, версию Android и использовался ли Bluetooth, USB-аудио или встроенный выход. При наличии Android platform tools сразу после воспроизведения ошибки сохрани лог:

```bash
adb logcat -d > cursed-drone-android-log.txt
```

Сессии хранятся в приватных данных приложения. Удаление приложения может удалить и их.

### Web

Укажи полное название и версию браузера, операционную систему, адрес страницы, аудиоустройство и полноэкранный режим. Открой консоль разработчика, воспроизведи ошибку и скопируй относящийся к ней вывод. Также напиши, помогла ли перезагрузка страницы.

### Нативная версия macOS

Запусти бинарник из Terminal и сохрани вывод:

```bash
./cursed-drone 2>&1 | tee cursed-drone-macos-log.txt
```

## Надёжность на концерте

Полевой ориентир разработчика: около 50% обычной загрузки и менее 80% максимальной замеченной загрузки на TrimUI Brick; на Pixel 8 Pro и в браузере macOS наблюдаемая нагрузка существенно ниже. Это не гарантия для любого патча и маршрута звука.

Перед выступлением:

- отрепетируй именно эту сборку, слоты памяти, аудиовыход и питание;
- не обновляй прошивку, браузер или приложение непосредственно перед концертом;
- сохрани рабочий релиз и файлы памяти отдельно;
- держи резервный источник звука.
